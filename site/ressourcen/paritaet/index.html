Paritätstrick

Ein Zaubertrick, den auch Computer beherrschen. Im Raster liegen Karten mit einer schwarzen und einer weissen Seite. Die Zauberin ergänzt eine Reihe und eine Spalte, «um es schwieriger zu machen». Danach dreht jemand eine einzige Karte um, und die Zauberin findet sie sofort.

Wie funktioniert der Trick?

Die zusätzlichen Karten werden so gelegt, dass in jeder Reihe und jeder Spalte eine gerade Anzahl schwarzer Karten liegt. Wird eine Karte umgedreht, stimmt das in genau einer Reihe und einer Spalte nicht mehr. Dort, wo sie sich kreuzen, liegt die Karte. Computer prüfen so, ob Daten unterwegs verändert wurden.
